## 🚀 How to Compile & Run

### ✅ Prerequisites
- GCC / G++ Compiler (MinGW on Windows, GCC on Linux/Mac)
- Any terminal / command prompt

### 🔧 Compile & Run (Example)
```bash
# Compile a .cpp file
g++ "filename.cpp" -o output

# Run the compiled program
./output        # Linux / Mac
output.exe      # Windows
```

### 💡 Quick Example
```bash
g++ "Armstrong number check.cpp" -o armstrong
./armstrong
```
